# FLPOS for Odoo 19

FLPOS is a lightweight Point of Sale extension by FlexSys that improves customer receipts and POS session closing reports without modifying Odoo Core.

## Current version

`19.0.1.1.1`

## Included features

- Dedicated receipt logo for each Point of Sale.
- Optional hiding of the default company logo on receipts.
- Optional hiding of the “Powered by Odoo” footer.
- Enhanced A4 POS session closing report.
- Product, payment, tax, discount, refund, and cash reconciliation summaries.
- Arabic/English labels for module settings.
- No POS Loader override.
- No POS Store patch.
- No JavaScript patch.

## Requirements

- Odoo 19
- Point of Sale (`point_of_sale`)
