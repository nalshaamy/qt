# Frequently Asked Questions

## Why did the receipt settings not change immediately?

Reload or reopen the POS after saving the settings. An already-loaded POS may still be using its previous configuration data.

## Can every POS use a different logo?

Yes. The receipt logo and visibility settings are stored per Point of Sale.

## Does FLPOS replace the company logo?

No. The dedicated receipt logo is separate from the company record.

## Does the module modify Odoo Core?

No.

## Can the closing report be saved as PDF?

Yes. Use the standard Odoo print action and save the generated report as PDF.

## Is a thermal closing report currently generated?

The configuration field exists for planned thermal-report support. The current production report included in this version is the enhanced A4 report.
