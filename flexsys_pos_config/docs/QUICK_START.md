# Quick Start

## Configure the customer receipt

1. Open **Point of Sale → Configuration → Settings**.
2. Select the Point of Sale to configure.
3. Find the **Receipt** section.
4. Enable **Custom Receipt Logo**.
5. Upload a receipt logo.
6. Enable or disable:
   - **Hide Default Receipt Logo**
   - **Hide “Powered by Odoo”**
7. Save the settings.
8. Reload the POS before testing a receipt.

## Print the closing report

1. Open **Point of Sale → Orders → Sessions**.
2. Open a closed POS session.
3. Select **Print**.
4. Choose **Enhanced Session Closing**.

The report can be printed or saved as PDF.
