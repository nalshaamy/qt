# Receipt Studio implementation status

## Implemented in 19.0.5.0.0

- Backend-only Receipt Studio workspace.
- Template selector.
- Component library.
- Live 80 mm preview canvas.
- Block selection and properties panel.
- Add, duplicate, delete, enable, reorder, and save blocks.
- Existing preview blocks: Logo, Company Information, Queue Number, Order Information, Customer Information, Items, Totals, Payments, QR, Custom Message, Divider, Spacer, and Footer.
- No POS runtime or OrderReceipt override is loaded.

## Not implemented yet

- Receipt compiler.
- Applying Receipt Studio templates to the actual POS receipt.
- Advanced image block editing.
- Production order-data binding inside Receipt Studio preview.
