# Coding Standards

- Follow Odoo 19 extension conventions.
- Never modify Odoo Core.
- Prefer model inheritance, XML inheritance, and QWeb inheritance.
- Keep configuration per `pos.config` unless a global setting is explicitly required.
- Avoid unnecessary stored fields and duplicated reporting data.
- Avoid JavaScript patches when a standard extension point is available.
- Keep translation-ready field labels and help text.
- Update documentation and changelog with every functional change.
