# Release Process

1. Define the release scope.
2. Implement one controlled feature set.
3. Upgrade the module on a clean test database.
4. Upgrade from the previous stable version.
5. Test receipts on each supported POS configuration.
6. Test reports with sales, refunds, discounts, taxes, and multiple payments.
7. Update documentation and changelog.
8. Freeze features for the release candidate.
9. Fix Critical and High issues.
10. Tag and package the stable release.
