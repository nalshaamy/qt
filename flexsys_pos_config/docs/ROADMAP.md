# Roadmap

The roadmap records planned work and does not guarantee delivery in a specific release.

## Stabilization

- Automated installation and upgrade checks.
- Receipt regression tests.
- Closing-report data tests.
- Multi-POS validation.
- Multiple payment-method validation.

## Closing reports

- Thermal closing report.
- Automatic report preview after successful register closing.
- Reprint action with persistent report identifier.
- Closing report generated-by and generated-at metadata.

## Receipt engine

- Configurable business footer information.
- Configurable customer message.
- URL-based QR generation.
- Optional marketing landing-page QR.
