# FlexSys POS Receipt — Odoo 19, version 19.0.1.0.3

Staging candidate: five requested improvements in one release.

- Compact vertical gaps around receipt data and products without resizing the original logo. The original ZATCA QR is never recreated.
- Arabic VAT group label when its Odoo name is exactly VAT Taxes / VAT / Value Added Tax; other tax groups are untouched. The VAT number label uses Arabic/English dynamically.
- Wrap long product names, keep amount/currency together, add product column header (QTY / ITEM / AMOUNT). Preserve native Odoo order lines for discounts and refund quantities.
- Place store address and registered VAT in a clearer two-column footer.
- Preserve the previous hide-price-per-unit-on-receipt rule, keep product discounts.

## Important

This is **not yet Odoo runtime tested**. Use a Staging instance, upgrade module, restart POS with fresh assets, print Arabic and English 80mm receipts, including multi-item, long names, refunds, partial payments, and tax-group combinations.

The translated VAT label is intentionally restricted to known strings. If other localization labels are used, capture a staging receipt and expand the map. VAT rates are taken from Odoo; never hard-code a 15% rate.

The original receipt logo and QR are not touched. Actual fiscal QR must be tested with ZATCA verifier.

Browser PDF page headers/localhost footer are browser print settings, not receipt content.
