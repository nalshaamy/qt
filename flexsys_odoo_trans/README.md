# FlexSys Trans Manager

Odoo 19 module for an independent warehouse inventory dashboard.

## URLs
- `/inv/manager/login`
- `/inv/dashboard`
- `/inv/dashboard/stock`
- `/inv/dashboard/movements`
- `/inv/logout`

## Installation
1. Copy `flexsys_odoo_trans` into the custom addons repository.
2. Commit and push to the Odoo.sh branch.
3. Update the Apps list.
4. Install **FlexSys Trans Manager**.
5. Assign **FlexSys Trans Manager / Administrator** to the backend administrator if needed.
6. Open **FlexSys Trans Manager > Independent Managers** and create a manager with a password of at least 8 characters.
7. Open `/inv/manager/login`.
