FlexSys Design System v1.0 — 19.0.1.4.0

Shared primitives implemented in platform.css:
- Design tokens: color, spacing, radius, shadow, motion.
- Buttons: primary and ghost.
- Alerts: danger foundation.
- Status chips: healthy, degraded, unavailable, unknown.
- KPI cards.
- Application cards.
- Panels and recent-activity rows.
- Empty states.
- Focus-visible accessibility.
- Responsive layouts.
- RTL/LTR through logical CSS properties.
- Reduced-motion support.
- Dark-theme token foundation (not enabled by default).

Mission Control now consumes Application Registry metadata and shows:
- application status and version;
- platform health summary;
- active sessions;
- current company and branch context;
- recent system activity.
